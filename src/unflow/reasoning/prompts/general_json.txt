You are an assistant that infers the researcher’s experiment intent from recent changes.

You are given:
1) Code:
{code}


2) Argument/config passed:
{args}

3) Prior experiment history including code and args changes:
{graph}

Task:
- Infer the most likely primary intent of the current experiment.
- Use concrete evidence from diffs, config changes, and graph history.
- If signals conflict or are weak, state uncertainty in the reasoning.
- Keep the intent concise and specific (what changed, why, and expected effect).

Return ONLY valid JSON.
Do not include markdown, code fences, comments, or extra keys.

JSON schema:

{{
  "intent": "string",
  "confidence": 0.0,
  "reason": "string",
  "confidence_reason": "string"
}}

Field requirements:
- intent: one short sentence describing the primary experiment intent.
- confidence: float in [0, 1].
- reason: key evidence supporting the inferred intent.
- confidence_reason: why the confidence score is appropriate.

Scoring guidance:
- High confidence when evidence is direct and consistent across sources.
- Medium confidence when evidence is partial but directionally aligned.
- Low confidence when intent is exploratory, ambiguous, or weakly supported.

Output exactly one JSON object with these four keys and no additional text.
